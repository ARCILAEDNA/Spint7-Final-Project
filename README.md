# ConnectaTel – Sprint 7

Este repositorio contiene el análisis realizado durante el Sprint 7 del caso ConnectaTel, una empresa de telecomunicaciones de México y Colombia.

El dataset `plans.csv` incluye el precio, los minutos incluidos, los GB incluidos y el costo por extra dependiendo del plan (Básico o Premium).
El dataset 'users_latam.csv' incluye la información de los clientes tal como edad, ciudad, fecha de registro, plan.
El dataset 'usage.csv' incluye el detalle de uso real como número de llamadas, duración de las llamadas, mensajes y su longitud.

## 📂 Contenido del repositorio

- `S7 Version-Estudiante-Project-ConnectaTel.ipynb`
  → Notebook principal con limpieza, EDA, distribuciones, outliers y conclusiones.
